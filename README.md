## github-tutorial

Hello! This is the testing repo for 599 where students will submit their test branch 🚀

Now that you're here...
Please follow the steps below:

1. Clone the GitHub Repo to your local computer using method of choice (GitHub Desktop, command line etc.)
2. Create a new Branch called "LASTNAME\_FIRSTNAME\_branch"
3. Publish your new Branch and Fork repo - say "yes I want to make this a fork" since you won't have write access to the repo
4. Edit the README.md file and write a brief description that you could use for your 599 project - If you already have one.. Great! Make it better in some way and submit that (add a photo? add in your contact info?)
5. Commit changes
6. Push Changes to remote origin
7. Take a screenshot of your GitHub forked repo with your README and **submit on Canvas to recieve a participation grade**

## GEM599 project



An area in Wetzin'kwa community forest is suitable for thinning. LiDAR data, aerial imagery and field collected data are needed for creating a model of this forest, and a suitable thinning scenario should be selected based on the analysis to the model. Several research has explored the accuracy of remote sensing data in tree delineation for thinning design compared to field collected data. However, the impact of remote sensing data (such as LiDAR data and aerial imagery) on decision-making in thinning scenarios has not been investigated. This article aims to compare the difference between optimum thinning scenario generated by only LiDAR data, only aerial imagery, and a combination of LiDAR data, aerial imagery and field collected data in the Wetzin’kwa community forest. For example, discussing the trade-off between budget and resolution, impact to residual trees and future fire risks.
